# Texas 42 and Walt: finite mathematics

Jason Yandell · 18 October 2026 · CC0 1.0 Universal

Two compact papers, intended to travel together or separately:

- [Texas 42: rules, worlds, and exact reduction](42.md) derives the finite game from domino incidence and distinguishes physical worlds from weighted beliefs.
- [Walt: one policy across hidden worlds](walt.md) defines information-consistent response, proves its Bellman and coherence properties, and states the conditional stabilization and certification results.

Sources are pinned to [mk5-main, revision 28edece4](https://github.com/jasonyandell/mk5-main/tree/28edece47b5cf11d57f32095d835b82d7e169bf0). Mathematical statements labeled **derived** have explicit arguments here; **mechanized** means the cited abstract Lean statement was checked. Code citations establish an implementation connection, not a verified refinement theorem. The Lean check passed for all fifteen exposed theorems with only standard Lean axioms; it does not verify the concrete game or runtime.

The manuscripts were consolidated from repository source audits and reviewed by AI agents. Derivations narrow or correct some historical source claims; citations identify provenance, not blanket endorsement. This is internal mathematical review, not external peer review. No empirical superiority, novelty, or universal optimality claim is made. Walt's mathematics is CC0; this publication does not relicense Zeb's MIT implementation.
