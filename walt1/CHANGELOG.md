# Changelog

## 0.1.0 - 2026-11-15

The first release: Walt, the level-1 scenario player of WALT.md v1.0, as
WebAssembly. `play` picks a seat's tile from its own hand and the public
plays, with the same request and move shapes as `@jasonyandell/zeb`.
`requestText` and `ask` expose the `walt1 play` text protocol.
