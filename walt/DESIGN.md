# walt — exact endgame information-set solver (v0)

The base layer of the endgame→up ladder ideated 2026-07-17 (see wiki: the
belief/policy/value algebra, MIGHT-#3; champion-design-review's "summit"
paragraph; lamir1-ceiling for the scar this must probe before climbing).
Named for the walker: the tile that looks like trash by beat-count but is
unbeatable when led, harvesting the count that rides the trick. v0 must be
able to *see* walkers; the ladder, if licensed, learns to *create* them.

## Objective

At an information set s of one seat m with ≤ 4 tiles per seat remaining,
compute the exact best response of m in the information-set game against a
**fixed, known field** σ for the other three seats (partner included):

    max over info-set strategies ρ of  E_{ω~b} [ U( terminal(ω; ρ, σ) ) ]

- One action per information set of m, consistent across worlds — this is
  the un-deletion of π from the continuation (strategy fusion killed by
  construction).
- v0 field: jud play nets, deterministic argmax. A cheap heuristic field is
  also wired for brute-force validation.
- U configs: (a) bidding-team points, defenders minimize — JudPlay's own
  target, for clean comparison; (b) make/set step utility at the bid line.

## Beliefs

Root worlds = exact enumeration of hidden-tile assignments consistent with
physics (played tiles, observed voids) — this is u. Weight configs:

- **W0 — uniform u.** The eq limit (g ≡ 0). Isolates term 2 of the gap
  (honest continuation under physics beliefs).
- **W1 — exact B(σ).** With a deterministic field, e^g degenerates to a
  0/1 filter: keep exactly the worlds in which σ would have played every
  observed non-m action. Computed by replaying candidate worlds through σ
  with net evals batched across the world dimension (MPS). Adds term 1.
  Caveat: only sound when the observed seats actually play σ (true in
  all-jud grading; false vs humans — that's where a soft e^g head returns).

W0 vs W1 under the same solver is the gap decomposition run as an ablation.

## Algorithm (deterministic field)

Recursion over nodes (public history from root, m's remaining hand, alive
world set with weights):

- At m's decision: for each legal a, advance; then per world, opponents'
  actions under σ are determined — partition worlds by the observed action
  sequence until m's next decision (or terminal). Node value under a =
  weight-mixture of branch values. Return max_a; record argmax (this IS the
  strategy at that info set).
- Leaves: exact scored payoff per world (zeb scoring).
- Memoization key: (m hand bitmask, canonical public-history key). The
  alive-world set is a deterministic function of the key given root set +
  σ, so the memo is sound. In-recursion opponent actions are generated by
  σ, so W1 consistency is preserved downstream with no re-filtering.
- Alive-world partitioning is where partner-reading lives: observing
  partner's σ-move filters b exactly. b = B(π), computed, not amortized.

Complexity: ≤ |worlds| × Π(mover branching) world-paths; at 4 tricks
≤ 34,650 × 4^4 ≈ 8.9M vectorized world-steps worst case, typically far
fewer after void/σ filtering. Field net calls: one batch per (frontier
opponent decision), batch dim = alive worlds, memoized on
(seat, hand-under-ω, history).

## Data layout (M5 Max)

- Tiles = ints 0..27; hands = uint32 bitmasks; worlds = struct-of-arrays
  uint32[N,3] (three hidden seats).
- Precomputed LUTs per declaration: effective-suit-of-led, beats[a][b],
  count[tile] (5-5:10, 6-4:10, 5-0:5, 4-1:5, 3-2:5), trump membership.
- Trick resolution vectorized over worlds via LUT gathers (numpy).
- Solver = CPU (numpy, optional numba kernel if profiling says so);
  belief filter + field evals = batched torch/MPS from the main process;
  grading throughput = multiprocessing over root positions (18 cores,
  leave headroom for the MPS feeder).
- Bench cap: any paired perf bench ≤ 10 min wall. All long processes log
  at least every 60s (events.jsonl + tail.log layout).

## Correctness gates (all pass before any grading number is believed)

- T1 known-world degeneracy: |worlds| = 1 ⇒ solver == brute-force best
  rollout vs σ.
- T2 exactness: on 2-trick endgames with ≤ ~12 worlds, enumerate ALL of
  m's pure info-set strategies explicitly; solver value == enumeration max.
- T3 dominance: solver value ≥ E[value of any fixed test policy] under the
  same (worlds, σ).
- T4 weight-split invariance: duplicating a world with split weight leaves
  value unchanged.
- T5 scoring parity: leaf payoffs == zeb's own scoring on replayed hands.
- T6 claim-vs-cash closure: root value == mean realized payoff when the
  computed strategy is actually played out across the alive worlds. The
  solver's claim must cash against its own simulation, exactly.

## Grading pilot (predictions registered on the issue BEFORE the run)

Paired seeds, all-jud table baseline vs same table with one seat consulting
walt once its tile count reaches the horizon (offense and defense graded
separately). Metrics: bidding-team points over the solve window (signed to
the walt seat's team), make/set flips, marks/hand; paired bootstrap CI via
the arena's existing stats path. Instrumentation: walker events — walt
leads a tile that wins in every alive world while ranking bottom-half by
global beat-count; log frequency and harvested count.

## Non-goals (v0)

No ladder climb, no distillation (that is the Lisý scar probe, filed
separately and gated on this layer), no stochastic fields, no auction, no
gus-head weights (returns when the field is not replayable).
