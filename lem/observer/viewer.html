What did training change?

A parameter is an adjustable number in the model. At each training step, a batch of recorded hands gives it guesses to make. The loss penalizes low probability on the tile that was actually played. Backpropagation calculates how to adjust those numbers; AdamW takes a small step.

The orange line is validation loss. Lower means the model assigns more probability to what happened. These hands are separate from training. The test hands used for the headline result are separate again.

2. What can it read?

Attention lets a token take information from earlier tokens. Each head learns its own reading pattern. Color shows the selected head’s weights when it predicts this tile.

Hover for a token’s weight. Future plays are absent. An attention weight is not proof that a token caused the guess.

3. The path through the model

tokens + positions→ attention→ MLP↻ 2 blocks→ 28 scores→ probabilities

A token is an ID for a tile, seat or marker. Its embedding is a learned list of numbers. Position adds a sense of order. Each block reads the prefix and transforms that running representation, adding its contribution back to it.

The MLP expands that representation, passes it through a smooth gate called GELU, then projects it back. Finally, softmax turns the 28 output scores into probabilities that add to one.

4. A first look at the units

These are the selected block’s MLP values before GELU, at the token making this prediction. Orange is positive; blue is negative. Click a square to follow one unit across the hand.

This is an instrument, not a name for what the unit does. A claim about its meaning needs many unseen examples, both poles, comparisons with untrained models, and causal tests.

This first model imitates recorded choices under Pour A’s fixed seat-0 bid-30 setting. It has no auction, cross-hand memory, or population of persistent player identities.
