> feat(burl/wax_museum): preload_tool_calls, menu_override, system_prompt_transform hooks
>
> Three opt-in extension points to run_decision_waxed so sweep runners can
> vary the belief_trajectory uptake protocol without forking the harness:
>
> - system_prompt_transform: edit the rendered system block after default
>   gate instructions are appended. Used by variant D (required_first).
> - preload_tool_calls: execute tools before the model's first turn and
>   inject results as a synthetic assistant pair. Used by variant B.
> - menu_override: swap the default menu_for lookup per-turn. Used by
>   variant E (strip belief) and variant F (belief_only).
>
> Companion sweep.py runs the six-variant Phase 1 sweep.

Three extension points added to `run_decision_waxed` enabling a six-variant sweep of [[belief-trajectory]] uptake protocols without forking the [[wax-museum]] harness. `preload_tool_calls` (variant B) injects belief into context before the model's first turn; `system_prompt_transform` (variant D) replaces default gate instructions with "Turn 1: call belief first"; `menu_override` (variants E/F) strips or isolates belief from the available menu. Phase 1 sweep runner lives in `scratch/` (gitignored per convention).
