## Key details

**New approach:** game-context Q&A (compact ~170 token prompts from real game records) replaces flashcard Q&A (isolated fact drills). The model sees game state and must answer about it, producing answers in-context rather than in isolation.

**Five question types** (see [[game-context-qa]]): `where_is`, `count_status`, `is_trump`, `what_beats`, `legal_moves`.

**Initial results at this sha (INVALID — grader bugs present):** ~40% overall, `legal_moves` 0%. These figures reflect grading of corrupted responses due to two bugs in `eval_comprehension.py`. See [[sources/1d3e1b7]] for the bug analysis. Correct results after fixing: 67% overall. See [[experiments/stage-0-v4-comprehension-eval]].
