## Key details

vLLM bundles its own pinned `transformers` version and applies its own model loading; applying the `Gemma4ClippableLinear → nn.Linear` monkey-patch (introduced in [[sources/9571a7b]]) before vLLM's model load causes a conflict. Fix: apply the patch only on the HF code path, not the vLLM path.

**Short-lived:** this commit is superseded hours later by [[sources/8724e93]], which removes vLLM entirely. The conditional patch is irrelevant once vLLM is gone.
