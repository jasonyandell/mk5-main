## Four-point analysis

1. **Corpus shape mirrored Layer 1's pathology** — adapter learned "Layer-1 Gemma" (eq-shy, is_legal-heavy) baked into weights
2. **Primer is too long** — ~40K chars per decision; attention dominated by rules text, not decision context
3. **Catastrophic tail call** — decision 6: dom 27 vs bot 9, Δ−24.81; without this one case, iter-0 mean tracks Layer 1
4. **Syntax fine, judgment regressed** — `<|tool_call>` format works correctly; failure is in which calls to make and what to commit

## vLLM-LoRA fix

vLLM 0.19 rejects `Gemma4ForConditionalGeneration` for LoRA. Fix: `hf_overrides={"architectures": ["Gemma4ForCausalLM"]}` at load time. No HF-generate fallback needed. Same vLLM path serves both base and LoRA inference.
