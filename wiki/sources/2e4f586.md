## Commit message

> fix(gus): glob-expand dataset paths inside nargs lists
>
> argparse nargs='+' passes literal strings ("gus/data/corpus_train_chunk_*.pt")
> rather than shell-expanded paths. Before this fix, a list input of one
> literal glob was handed to Path() verbatim and torch.load() failed with
> FileNotFoundError. Now we expand globs whether the input came as a plain
> string or a list.
>
> Found during the overnight 1000-game pipeline run — 100g baseline finished
> clean (eval π_me 59.5%), 1000g crashed on corpus load.

Infrastructure fix enabling chunked corpus loading. Also incidentally records that the
100g overnight baseline reached π_me 59.5% (close to the 57.9% in [[gus-4head-baseline]]).
