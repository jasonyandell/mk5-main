## Joint-world tensor shape

Two new optional fields on `DecisionRecordGPU` (fixed-sampling path only):

| Field | Shape | Content |
|---|---|---|
| `world_hands` | `[M, 3, 7]` | Sampled opponent hand layouts per world |
| `q_per_world` | `[M, 7]` | Oracle Q per action per world |

These preserve the raw joint (belief, Q) distribution that `compute_eq_pdf` previously collapsed
into a marginal. Required for the LAMIR-critical Q_head: look-ahead belief re-weighting becomes
a cached `Σ_m w_m · Q_m` re-weight rather than a re-query of the oracle.

## Five-head architecture committed

| Head | Input | Output | Target |
|---|---|---|---|
| `belief_head` | state | `[84]` P(dom ∈ seat) | True hand posterior |
| `V_head` | state | scalar | Oracle mean E[Q] |
| `π_me_head` | state | `[7]` softmax | Oracle argmax action |
| `world_encoder + Q_head` | (state, world_layout) | `[7]` Q per action | Per-world oracle Q |
| `π_opp_head` | (state, opp_seat) | `[7]` softmax | Opponent oracle argmax (deferred to v2) |

Target parameter budget: ~760K params total. Zeb-class.

## Training stages

| Stage | Heads | Success bar |
|---|---|---|
| v0 | belief only | top-1 > 50% on held-out (beats Zeb's 39%) |
| v1 | all 4 heads | π_me bot-match > 80%; Q_head MAE < 3 Q-points |
| v2 | add π_opp + LAMIR look-ahead | bot-match improves over v1 |

## Tire-kick findings

Single-game validation on eval seed 900000, M ∈ {10, 100, 2400-adaptive}:
- r=0.79 at M=10 was sampling-noise artifact; does not persist
- Belief-Q correlations converge by M~100-500; strongest pairs settle at r≈0.2-0.4
- Q-std is position-intrinsic and stable across M (~23 at decision 0)
- Adaptive SEM<0.5 converges in ~10s/game on MPS; file ~6 MB/game

## MPS fallback

Generator now falls back to MPS (Apple Silicon) when CUDA unavailable, rather than
hard-failing. Enables local tire-kicking on the M5 Max without a GPU node.
