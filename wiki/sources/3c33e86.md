## Training details

- **Data:** 31,830 examples × 3 epochs on [[modal]] B200
- **Batch size:** 16 (was 4 + gradient accumulation)
- **Gradient checkpointing:** disabled — model fits in B200 VRAM at batch_size=16
- **Speedup:** 1.4× faster than prior config
- **Per-epoch HF checkpoints** for adapter recovery at any epoch
- **Final:** loss 0.06, 97.4% token accuracy

## Eval fixes applied

All four fixes needed to get valid results:
1. EOS token 106 added (from [[sources/1d3e1b7]])
2. Left-pad slicing fixed (from [[sources/1d3e1b7]])
3. Thinking mode disabled at inference
4. Thinking-block marker cleanup from response text before grading

## Flexible grader

New `grade_offline.py` — see [[decisions/flexible-grader]] for design. The shift from rigid to flexible grading moved `is_trump` from 0% to 100% — not because the model improved, but because it was being graded correctly for the first time.
