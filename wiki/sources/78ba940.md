## Full revert

Scratchpad validation is abandoned for now. `star_loop.py` returns to simple [[k1-grading]] (pass / fail / illegal / parse_fail). The scratchpad code (`validate_scratchpad.py`, `enrich_narrations.py`) is kept in the repo for future use.

> Scratchpad validation was too strict - 64.5% invalid, only 5 traces. Reverting to K1-only approach that showed 34% to 40% improvement.

The "34% to 40% improvement" reference is to the pass-rate range observed across earlier [[star-harness]] runs with simple K1.

**Random subset sampling added:** each iteration now draws a different random subset of the narration corpus via `--subset N`, adding diversity across iterations instead of running the same examples repeatedly.

## Lesson encoded

Format-bootstrapping must precede fact-validation. See [[scratchpad-validation]] for the preserved lesson. The scratchpad approach is not abandoned in principle — it is deferred until the model can reliably produce the format.
