## Key finding (verbatim)

The bug: Gemma 4's Jinja chat template wraps the render loop in `{%- if message['role'] != 'tool' -%}` — every `role="tool"` message is silently dropped. Every Burl rollout before this commit ran with tool outputs invisible to the model.

## What this introduces

- `burl/wax_museum/`: new hard-gated HATEOAS harness where the tool surface is staged (`explore_game` → `probe_*` → `commit_play`), forcing the model to probe outcome distributions before committing
- Tool-response shape fix applied throughout the harness
- `on_chunk` streaming callback added to `gemma_local.generate_native`
- PRACTICALITIES §9 and §10 appended
