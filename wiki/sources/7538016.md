> feat(lem): STaR harness — inference, K1 grading, R1 rationalization
>
> The heart of Stage 1. Modal function that:
> 1. Runs Gemma on narration prompts (with optional LoRA adapter)
> 2. Parses the model's action from the thinking channel output
> 3. Grades K1: did Gemma's E[Q] >= bot's E[Q]?
> 4. On pass: keeps the full response as a training trace
> 5. On fail/illegal: rationalizes (reveals correct action, asks why, keeps that)
> 6. Outputs JSONL training set for the next LoRA iteration
>
> Tested on 5 examples: 1 pass (20%), 2 fails rationalized, 2 illegal rationalized.
> All traces collected. Pipeline works end-to-end.
>

## Key details

- 6-step pipeline described in commit message is the canonical Stage 1 loop body.
- Optional LoRA adapter parameter: loads [[stage-0-adapter]] (or any HF adapter repo) via `PeftModel.from_pretrained`, merges and unloads before inference.
- Parse step extracts the model's chosen domino from the thinking-channel output.
- K1 grade: `E[Q][gemma] >= E[Q][bot]` (using grading data embedded in JSONL from [[b99c64d]]).
- R1 rationalization prompt: reveals bot's action, asks Gemma to justify it; resulting trace is kept regardless of original outcome.
- Output JSONL is the input for the next LoRA step.
- Smoke test result: 1/5 pass (20%), 2/5 K1-fail rationalized, 2/5 illegal rationalized. All 5 traces collected.
