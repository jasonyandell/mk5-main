## Key fixes

**PEFT gradient fix:** `Gemma4ClippableLinear` inherits from `nn.Module`, which PEFT cannot target for LoRA. Monkey-patching it to inherit from `nn.Linear` at import time restores gradient flow. Source: huggingface/peft#3129. Immediately validates: loss 32 → 0.001 in 40 steps, 100% token accuracy. This unblocks the training run that completes in [[sources/df73c8d]].

**bf16 swap:** `GradScaler` fails when gradient checkpointing is enabled. bf16 does not use `GradScaler`; the switch eliminates the failure mode.

**Modal timeout:** bumped to 4 hours to accommodate full training runs.

**Inference adapter loading:** `modal_app.py` `generate()` now accepts `--adapter` (HuggingFace repo id). Loads via `PeftModel.from_pretrained`, merges weights into base model, unloads for clean inference. This is the path used in [[experiments/second-gemma-contact]].
