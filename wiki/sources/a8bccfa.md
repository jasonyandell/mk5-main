## Key claims from `lem/OVERVIEW.md`

**North star:** E[Q] delta vs. the bot it replaced, measured on a held-out set of seeds, rising over training iterations.

**Two-stage plan:**
- Stage 0 ([[rules-adapter]]): teach [[gemma-4-e2b]] what Texas 42 is via a rules primer + synthetic Q&A corpus generated by the game engine, then LoRA fine-tune via [[lora-unsloth]]; gate: parsing sanity check on held-out narrations.
- Stage 1 (STaR on trick-6 decisions): generate games, narrate, filter to trick-6 decisions with real choice and clear E[Q] gap, run inference, grade with [[k1-grading]], rationalize failures with [[r1-rationalization]], LoRA step on kept traces, iterate until E[Q] delta plateaus.
- Stage 2+: widen the curriculum backward trick by trick.

**Design-choice table highlights:**

| Choice | Value |
|---|---|
| Base model | Gemma 4 E2B — phone-class, Apache 2.0, native thinking channel |
| Narrator framing | "You are taking over for a bot" — natural voice + baseline + realistic state distribution |
| Game gen policy | E[Q] greedy, N=10 — verified during zeb, not much worse than N=100 and cheaper |
| K1 keep rule | Keep iff `E[Q][gemma] >= E[Q][bot]` — self-sharpens as Gemma improves |
| R1 failure handling | STaR rationalization: reveal bot's action, ask Gemma to justify it, keep that rationale |
| LoRA fine-tune | [[lora-unsloth]] — only sane option on 3050 Ti; Unsloth has a Gemma 4 recipe ready |
| Dataset home | HuggingFace — shared artifact between local, Vast, and Modal compute |
| Variance handling | Filter out, don't correct — refuse to train on states where strategy doesn't exist |

**Gaps deliberately left open:**
- Exact variance filter thresholds (δ, σ_max) — start permissive, tighten from wandb
- Stage 0 corpus size and category mix — depends on parsing sanity check result
- Whether the rules primer stays in the system prompt forever or gets distilled into weights
- When to ratchet from Stage 1 to Stage 2 — only after Stage 1 clearly plateaus
- Whether R1 rationalization is enough or DPO-style preference learning is needed for Stage 3+
- Training hyperparameters — LoRA rank, LR, epochs; start from Unsloth Gemma 4 defaults

## Key claims from `lem/narrate/OVERVIEW.md`

**Voice rules:**
- Second person for the narrator ("You play the 6-6").
- Third person for the other three players ("Player 1 follows with the 5-2").
- Name relationships explicitly on first reference ("your partner, Player 1").
- State facts, not strategy — no "you should have played X" commentary in the baseline version.
- Count points at the end of every trick.
- Domino names in `H-L` form (`6-6`, `5-3`).

**Borrowed from [[forge]]:**
- Hand dealing from seed (`forge/eq/generate/deals.py`)
- Bidder (`forge/bidding/`)
- Game play with E[Q] (`forge.eq.generate.pipeline.generate_eq_games_gpu`)
- Stage 1 oracle checkpoint (`forge/models/domino-qval-large-*.ckpt`)
- Domino ID → pips (`forge/eq/viewer.py::domino_id_to_pips`)
- Declaration names (`forge/eq/viewer.py::DECLARATION_NAMES`)
- Suit/trick logic (`forge/oracle/tables.py`)

**Deliberately out of scope at v0:**
- Batch mode / multiple games
- File output (stdout only)
- `--stop-at-narrator-turn` truncation flag (designed for easy addition, not yet wired)
- `--show-eq` counterfactual body (flag exists, body absent)
- HuggingFace upload
- Narrations for all 4 perspectives from one game

**Open voice questions** (to resolve from first output):

- How much trick-state to restate each trick
- Whether [setup] should include full declaration trump ordering or assume [[rules-adapter]] knowledge
- Closing line format

## Key claims from `lem/rules/primer.md`

Scope: "straight tournament 42 only." Anything else (Nel-O, Plunge, Splash, Sevens, regional variants) is out of scope.

The "Facts this primer commits to" section provides self-verifying ground truth for [[rules-adapter]] training and eval. Selected facts:

- 28 dominoes, double-six set; 4 players in 2 fixed partnerships; 7 dominoes per player, no boneyard.
- Exactly 7 tricks per hand; hand worth exactly 42 points (35 count + 7 trick points).
- Five count dominoes: 5-5 (10), 6-4 (10), 5-0 (5), 4-1 (5), 3-2 (5); all other 23 dominoes worth 0.
- Trump declarations reduce to: one of 7 pip suits, doubles-as-trump, or no-trump.
- When a pip suit S is trump, every domino containing pip S is trump; S-S double is highest trump.
- When doubles are trump: exactly the 7 doubles form trump, ranked 6-6 high through 0-0 low; a double is not a member of its pip suit.
- The 6-4 is trump if and only if the trump suit is sixes or fours.
- Led suit rule: trump if the led domino is trump; otherwise the higher pip of the led domino.
- A player must follow the led suit if and only if they hold at least one domino of that suit.
- If any trumps are played, the highest trump wins; otherwise the highest domino of the led suit wins.
- Bidder's team makes the bid iff they take at least as many points as the bid value (point bids 30–41) or all 42 points (mark bids); 1 mark = 42 points.
