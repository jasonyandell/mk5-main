> fix(burl): Opus parallel-tool-use lock for claude-agent-sdk in-process MCP
>
> Opus 4.7 emits multiple tool_use blocks per assistant message. SDK
> spawns concurrent handler tasks; MCP shared tool cache isn't
> concurrency-safe — race wedges with "Stream closed" or silently
> terminates at turn 1. Fix: process-global asyncio.Lock monkey-patch
> on _handle_sdk_mcp_request. Validated vs HTTP transport alternative.
>
> Open bug: ThinkingBlock.thinking returns empty despite non-zero tokens.

`asyncio.Lock` monkey-patch on the Agent SDK's `_handle_sdk_mcp_request` serializes parallel tool handlers spawned by Opus's multi-block tool-use. Applied at top of `burl/haiku_spike/agent.py` so all callers inherit it. HTTP MCP transport is a validated alternative but more invasive. Open bug: `ThinkingBlock.thinking` string is empty despite non-zero `output_tokens`.
