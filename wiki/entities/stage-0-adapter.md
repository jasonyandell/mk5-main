## What it is

The Stage 0 Adapter is the LoRA fine-tune of [[gemma-4-e2b]] produced by LEM's Stage 0
training run. It is published at HuggingFace as `jasonyandell/gemma-4-e2b-texas42-stage0`.
(commit message @ df73c8d)

## Training provenance

- **Base model**: [[gemma-4-e2b]] (`google/gemma-4-E2B-it`)
- **Training data**: 3500-example Q&A corpus, 7 categories (trump membership, led suit,
  legal moves, trick winners, count math, hand tracking, void inference), generated by the
  game engine with engine ground truth
- **Method**: [[lora-unsloth]] LoRA fine-tune on [[modal]] L4 (22GB), bf16, 1 epoch,
  208 steps, ~60 minutes
- **Wandb run**: `jasonyandell-forge42/lem-stage0`

(commit message @ df73c8d)

## Loss curve

Loss: 32 → 15 → 2.8 → 0.001 in 40 steps. 100% token accuracy by step 50. Converged well
within the 1-epoch budget. (commit message @ df73c8d)

## Inference loading

Loaded via `PeftModel.from_pretrained`, then merged and unloaded before generation. The
`Gemma4ClippableLinear` monkey-patch must be applied in both the training function and the
inference function before the model is loaded. (commit message @ 9571a7b)

## What it fixed

Compared to base [[gemma-4-e2b]] on the same prompt (seed 42, fives trump, trick 6):

| Dimension | Base | + Stage 0 |
|---|---|---|
| Hand tracking | Played already-gone domino (illegal) | Correctly read remaining hand |
| Final answer | Illegal move | Legal and correct |
| Trump membership | 6-4 called trump under fives | 4-4, 6-4 still called trump (remaining gap) |

(lem/OVERVIEW.md @ 24ae55a; see [[experiments/second-gemma-contact]])

## Remaining gap

Trump membership errors persist: 4-4 and 6-4 are still called trump under fives-trump.
The Q&A training format did not fully transfer to narration-context reasoning. The
expectation is that [[star]] Stage 1 closes this gap through practice rather than drilling
— the K1 grading criterion penalizes trump errors when they cause bad plays.
(lem/OVERVIEW.md @ 24ae55a)

## Downstream use

This adapter is the base for [[star]] Stage 1 STaR iterations. It must pass a parsing
sanity check on held-out narrations before Stage 1 begins; at this frontier that gate has
not yet been formally run. (lem/OVERVIEW.md @ 24ae55a)
