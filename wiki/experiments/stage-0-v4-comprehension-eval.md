## Summary

Comprehension evaluation of [[v4-adapter]] on 100 held-out examples from the eval seed range. First rigorous measurement showing [[gemma-4-e2b]] demonstrably knows Texas 42 as a comprehension task. Overall accuracy: 67%.

([lem/OVERVIEW.md @ 2f11f32](../sources/2f11f32.md))

## Setup

- **Adapter:** [[v4-adapter]] (`jasonyandell/gemma-4-e2b-texas42-stage0-v4-full3ep` — the 3-epoch final; per-epoch checkpoints `-full3ep-ep1`…`-ep3` also on HF)
- **Eval set:** 100 held-out examples from eval seed range (7,725 eval examples generated by `generate_comprehension.py`)
- **Question types:** 5 types from [[game-context-qa]] — `is_trump`, `where_is`, `legal_moves`, `count_status`, `what_beats`
- **Inference:** thinking mode DISABLED
- **Grading:** [[decisions/flexible-grader]] (`grade_offline.py`) — extracts facts from free-form responses, not rigid pattern matching

([lem/gemma_star/eval_comprehension.py + grade_offline.py @ 3c33e86](../sources/3c33e86.md))

| Type | Accuracy |
|---|---|
| is_trump | 100% |
| where_is | 90% |
| legal_moves | 70% |

> The model knows Texas 42. It doesn't say "Bridge" anymore.

## Significance

**is_trump at 100%** closes the stubborn 6-4-under-fives error that persisted through first, second, and third contacts (see [[experiments/first-gemma-contact]], [[experiments/second-gemma-contact]], [[experiments/third-gemma-contact]]). The v4 game-context curriculum succeeded where prior Q&A rounds left a residual error.

**what_beats at 15%** is the remaining weak spot. Ranking dominoes in context (which specific domino wins THIS trick given the led suit, trump, and plays so far) is harder than membership (is this domino trump?). Context-sensitive ranking requires integrating multiple facts simultaneously.

## Prior eval was wrong

Earlier eval runs (4729dad) showed ~40% overall with `legal_moves` at 0%. Both figures were artifacts of two bugs in the eval pipeline — not model failures. The same model, same adapter, graded correctly with the [[decisions/flexible-grader]] → 67%. See [[sources/1d3e1b7]] for the bug analysis.

The bugs:
1. **EOS token mismatch** — `generate()` stopped on `<eos>` (token 1) but Gemma 4 uses `<turn|>` (token 106); responses were truncated mid-answer.
2. **Left-pad slicing error** — `attention_mask.sum()` counted padding as input, causing trailing input tokens to appear in the extracted "response."

## Superseded

The 67% overall figure was superseded twice: first by [[v9-adapter]]'s 83% (14 categories,
same [[game-context-qa]] lineage on [[qwen3-1.7b]]), then by v10-maskfix's 86% (see
[[v10-maskfix-breakthrough]]). This page's 5-category, Gemma-base result is
historical — it is the eval that proved the model "knows Texas 42" at all, not the current
best number.
