## Summary

[[w42]] has a paired raw-public-state versus raw-plus-v0-strategy-tags model
comparison on the same train/eval split used by [[w42-raw-public-state-baseline]].

- script: `w42/v0_strategy_tags_baseline.py`
- artifacts: `w42/v0_strategy_tags_baseline/`
- raw baseline artifacts reused: `w42/raw_public_state_baseline/`
- feature delta: adds [[w42-strategy-tags-v0]] global and action-local public-state
  tags to the raw tokens, voids, and candidate action id
- data slice: 100 generated train games and 20 held-out eval games from the
  local [[gus]] joint-world corpora

On 560 held-out eval decisions, the best raw-plus-v0 epoch reached 2.000 mean
regret and 63.93% oracle-best action match. The paired raw best from the prior
run was 2.471 mean regret and 59.64% match. The reloaded raw final checkpoint
exactly reproduced its prior final metrics, then the tagged final checkpoint
improved mean regret by 0.734 Q-points on the same eval loader.

## Key Question

Do the cheap v0 public-state/action-local strategy tags improve the same small
w42 policy model over the raw public-state/action-input baseline on the same
split and metrics?

## Method

| field | value |
|---|---|
| report owner bead | `t42-csw6.11` |
| evidence mode | w42 model comparison with forge/Gus oracle labels |
| ruleset / score mode | existing Gus corpus semantics |
| decision slice | all 28 decisions per game in the small v1 corpora |
| train/eval split policy | `w42-seed-bucket-v1` via existing train and eval corpora |
| statistical test | held-out mean regret, match rate, near-tie rate, v0 tag-group slices |
| success criterion | paired report-only evidence that v0 tags help or do not help |

The tagged model keeps the raw baseline's core transformer, void encoder,
candidate-action embedding, action hidden size, optimizer, epoch count, batch
size, and random seeds. The architecture delta is limited to small public-state
tag adapters: 68 global tags and 32 action-local tags per action slot project
into `d_model=64`, then add into the existing state/action streams before the
same action scorer.

## Findings

| finding | evidence | metric | status |
|---|---|---|---|
| v0 strategy tags improved the tiny w42 model on the paired small eval split. | `metrics.json` | best mean regret 2.000 vs raw best 2.471 | model-comparison evidence |
| The tagged model remained far behind the cheap oracle-sampling boss baseline. | `metrics.json` | tagged best 2.000 vs `E[Q] N=10` 0.118 | caveat |
| The largest diagnostic slice gains appeared in action-local pressure/donation groups. | `bucket_metrics.csv` | donation-window delta -2.433 regret, count-pressure delta -2.431 regret | underpowered slice evidence |
| Raw final checkpoint re-evaluation was paired correctly. | `metrics.json` | reloaded raw final exactly matched prior final: 2.834 regret, 56.61% match | provenance check |

## Caveats

- The train slice is only 2,800 decisions from 100 games, and the eval slice is
  only 560 decisions from 20 eval-only games.
- The comparison is paired by split, seeds, metrics, and core model shape, but
  the tagged model necessarily adds small tag-adapter parameters.
- This is a single-seed research run, not a confidence interval or multi-seed
  statistical result.
- The bucket slices are v0 tag-group activation slices, not per-concept causal
  ablations and not claim-ledger tests.
- `E[Q] N=10` remains much stronger on this eval slice.
