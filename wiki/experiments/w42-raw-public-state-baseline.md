## Summary

[[w42]] has a first cheap raw public-state/action-input model baseline:

- script: `w42/raw_public_state_baseline.py`
- artifacts: `w42/raw_public_state_baseline/`
- model input: Gus public-state tokens, attention mask, void features, and a
  candidate action id
- labels: oracle-best action derived from marginal `e_q`
- data slice: 100 generated train games and 20 held-out eval games from the
  local [[gus]] joint-world corpora

This is a floor-setting baseline, not a competitive policy. On 560 held-out
eval decisions, the best epoch reached 2.471 mean regret and 59.64% oracle-best
action match. `E[Q] N=10` on the same eval rows reached 0.118 mean regret and
90.00% match.

## Key Question

How much policy signal can a minutes-scale w42 model extract from raw public
state plus candidate action id before adding cheap strategy tags or richer
Winning 42 concept buckets?

## Method

| field | value |
|---|---|
| report owner bead | `t42-csw6.10` |
| evidence mode | w42 model with forge/Gus oracle labels |
| ruleset / score mode | existing Gus corpus semantics |
| decision slice | all 28 decisions per game in the small v1 corpora |
| train/eval split policy | `w42-seed-bucket-v1` via existing train and eval corpora |
| statistical test | held-out mean regret, match rate, near-tie rate |
| success criterion | report-only floor baseline with strict provenance |

The model uses the existing Gus `TransformerEncoder` and `VoidsEncoder`, but it
does not modify Gus code or training defaults. It scores each legal candidate by
concatenating the encoded public state with a learned candidate-action embedding.
Oracle `e_q` is used only to derive the supervised target and regret metrics.

## Findings

| finding | evidence | metric | status |
|---|---|---|---|
| Raw public state plus action id learns above random-looking behavior but remains far from the oracle-sampling boss baseline. | `metrics.json` | best mean regret 2.471 vs `E[Q] N=10` 0.118 | underpowered floor baseline |
| More epochs did not monotonically improve held-out regret on this tiny slice. | `run.json` history | best epoch 3; final epoch 8 worsened to 2.834 | report-only caveat |
| The baseline preserves the public-state boundary. | `manifest.json` | only `tokens`, `attention_mask`, `voids`, `candidate_action_id` used as inputs | no leakage found in script-level check |

## Caveats

- The train slice is only 2,800 decisions from 100 games, and the eval slice is
  only 560 decisions from 20 eval-only games.
- The model is intentionally tiny and tuned only enough to establish a floor.
- MPS execution is fast but not a multi-seed statistical result.
- The current script saves the final checkpoint; the best-epoch metrics are
  recorded, but early-stopping checkpoint restore is not yet implemented.
- This baseline does not answer whether strategy tags or chapter-derived concept
  buckets help; it only establishes the raw-only comparison point.
