## Summary

[[w42]] has a cheap paired family-drop ablation probe over the rich public-tag
surface from [[w42-rich-tag-many-signal-probe]].

- script: `w42/strategy_tag_family_ablations.py`
- artifacts: `w42/strategy_tag_family_ablations/`
- W&B run: `https://wandb.ai/jasonyandell-forge42/w42/runs/qvq73ix6`
- method: retrain the same small raw-plus-v0-plus-rich model while zeroing one
  rich concept-family proxy set before projection
- data slice: 100 generated train games and 20 held-out eval games from the
  local [[gus]] joint-world corpora

The headline is conservative: no family drop moved best mean regret by the
pre-registered practical threshold of `0.15` Q-points versus the full rich
retrain. The largest apparent hurt was dropping no-trump/doubles proxies
(`+0.107` regret); the largest apparent help was dropping off-protection proxies
(`-0.051` regret). On this single seed and 560-decision eval slice, those are
best read as weak/noisy marginal signals, not supported strategy-family claims.

## Key Question

Which rich tag families carry useful policy signal beyond the raw public state
and v0 strategy-tag surface, and which look decorative or noisy on the current
small split?

## Method

| field | value |
|---|---|
| report owner bead | `t42-csw6.15` |
| evidence mode | cheap paired retraining ablation with forge/Gus oracle labels |
| ruleset / score mode | existing Gus corpus semantics |
| decision slice | all 28 decisions per game in the small v1 corpora |
| train/eval split policy | `w42-seed-bucket-v1` via existing train and eval corpora |
| statistical test | paired split, seed, model shape, regret/match/tail metrics; no CI |
| success criterion | identify large family drops or report weak/noisy marginal signal |

The ablation model keeps the raw/v0/rich architecture from
[[w42-rich-tag-many-signal-probe]]. Each family-drop variant zeros selected rich
global/action proxy columns before the rich projections. Raw tokens, voids,
candidate action id, and all v0 strategy tags remain available.

This is not a pure causal detector test. Families overlap, the feature groups
are public proxies, and retraining can absorb missing columns through correlated
v0/rich signals. The result is useful for prioritizing follow-up work, not for
claim-ledger promotion.

## Findings

| finding | evidence | metric | status |
|---|---|---|---|
| The rich feature surface still looks slightly positive as a bundle, but the effect is small. | W&B run `qvq73ix6`; `ablation_matrix.csv` | rich disabled 2.011 vs full rich 1.970, delta +0.042 regret | weak single-seed evidence |
| No individual family drop produced a practically large effect. | `ablation_matrix.csv` | largest hurt +0.107; largest help -0.051; threshold was 0.15 | noise-band evidence |
| No-trump/doubles, 84, scoring, and walker/endgame were the largest apparent hurts when dropped. | `ablation_matrix.csv` | +0.107, +0.078, +0.053, +0.043 regret | prioritization hint only |
| Off-protection got better when dropped, which argues against treating the current proxy as clean signal. | `ablation_matrix.csv` | drop off-protection delta -0.051 regret | possible proxy noise |
| Diagnostic bucket gains remain larger than causal family-drop effects. | `bucket_metrics.csv` from rich run vs ablation matrix | pounce/count slices show big raw-vs-rich gains, but dropping families barely moves aggregate regret | correlation warning |
| The model remains far behind `E[Q] N=10`. | `metrics.json` | full rich 1.970 vs `E[Q] N=10` 0.118 mean regret | caveat |

## Claim-Ledger Impact

no claim-ledger change

This bead runs model-feature ablations, not enumeration, oracle rollout,
claim-specific counterfactuals, belief calibration, or Burl trace review. It
therefore does not move any Winning 42 claim status. It narrows the next
claim-ledger path: implement cleaner, less-overlapping detectors before treating
no-trump/doubles, 84, scoring, off-protection, or pounce buckets as claim
evidence.

## Caveats

- This is a single-seed research run on only 560 eval decisions.
- Family masks overlap; some columns appear in more than one conceptual story.
- Raw and v0 tags remain available, so drops test marginal rich proxy signal,
  not the whole concept family's detectability.
- The rich-disabled row still has the rich projection modules with zero inputs,
  so it is an architectural control, not the exact prior v0 checkpoint.
- The 84 and walker/endgame source slices are underpowered, and the family-drop
  aggregate is not a regime-isolated evaluation.
- No Burl traces, hidden-hand labels, or private table-talk inputs were consumed.
