## E[Q] N=10 Provenance

The boss row was computed by the raw baseline script, not by an unsupported
standalone E[Q] command. The run command recorded in the raw manifest was:

```bash
scratch/w42/raw_public_state_baseline.py --train /Users/jason/code/mk5-main/gus/data/corpus_train_100.pt --eval /Users/jason/code/mk5-main/gus/data/corpus_eval_20.pt --train-limit 2800 --eval-limit 560 --epochs 8 --batch-size 256 --seed 42 --split-seed 42 --eval-seed 43 --output-dir scratch/w42/raw_public_state_baseline
```

The script's default and recorded config set `eq_n: 10`. Internally,
`EQNWrapper` takes the first `N` per-world Q rows for each eval decision, and
`evaluate_eq_n` averages those 10 rows, masks illegal actions, picks the best
legal action under the sampled estimate, then scores regret against the full
marginal `e_q` label. The raw manifest records oracle/world sampling as
`first-N deterministic`.

## Alignment With Current And Future Runs

The raw baseline already uses this exact slice, so its headline comparison is
directly anchored: best raw regret `2.471069` versus `E[Q] N=10` regret
`0.117969` on the same 560 eval decisions.

The existing [[gus-strategy-tags-probe]] rows are useful context but not this
exact reusable slice. That page reports a 100-game full-decision probe where
`E[Q] N=10` reached `0.191` mean regret on 560 eval rows, plus early-decision v2
probes where `E[Q] N=10` reached `0.167`. Those rows establish that cheap tags
can improve tiny public-state policies, but future w42 tag runs should either:

- rerun tag variants on the raw baseline's exact eval corpus and limits, then
  compare to the `0.117969` boss row above; or
- explicitly state that a different corpus/slice is being used and create a new
  boss row for that slice.

Future comparison tables should keep the columns `policy`, `configuration`,
`mean_regret`, `match_rate`, `near_tie_rate_regret_lt_0_5`, `eval_n`, and
`artifact`. That makes raw, cheap-tag, richer chapter-tag, and concept-bucket
runs line up without mixing incompatible slices.

## Caveats

- The slice is small: 20 eval games and 560 decisions.
- `E[Q] N=10` uses the first 10 per-world Q rows, not multiple random N=10
  samples per decision.
- The raw model table is a one-seed floor baseline, not a multi-seed statistical
  result.
- The source corpora live under the local main checkout path recorded by the raw
  run, while this worktree documents the slice from already-produced artifacts.
